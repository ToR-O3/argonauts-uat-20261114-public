Executive summary

wordfreq に --exclude FILE を追加し、1行1語で指定した語を集計から外せるようにします。空行と # 開始行を読み飛ばし、既存と同じ str.casefold() で大小を同一視します。除外FILE不存在は分かるstderrと終了コード2にします。

help、READMEの使い方、追加試験を届け、未指定互換・Unicode正規化・既存形式を守ります。利用者像と業務上の時期は未確認で、需要の根拠は今回の依頼に限られます。

Problem

現CLIにはtop・min-count・formatがあり、指定語一覧で外す選択肢はありません。頻度閾値だけでは、回数の多い特定語を指名して外せません。現場の時間損失や売上効果は提示されていません。

Solution

python -m wordfreq input.txt --exclude excluded.txt と指定します。指定語の全出現を外し、残る語は従来の規則で表示します。Straße STRASSE と除外行 STRASSE はcasefoldで同じ語として扱います。不存在は成功した空結果ではなく失敗として通知します。

What makes it different

回数によらず語を指名して外せる既存CLI拡張です。外部前処理の利用実態や競合優位は未調査であり、市場や独自性を主張しません。

Who it serves

既存CLIで特定語を外したい利用者を対象と推定します。保守・品質担当は試験と未指定互換を根拠に判断します。特定の職種・個人・規模は未確認です。

Success criteria

  • 指定語が消え、残存語の回数と同数初出順を保持。
  • 空行と生の行頭#を無視し、Unicode casefoldで照合。
  • 除外FILE不存在は説明stderrとexit2。
  • help/READMEと追加試験で使い方・互換性を確認。
  • 対抗指標は既存出力・エラー・依存・CIの意図しない変更がないこと。
