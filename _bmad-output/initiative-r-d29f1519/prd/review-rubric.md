# PRD — Rubricレビュー

判定: 未承認提案の範囲と下流で守る境界を示すPRDとして利用できる。確定仕様ではなく、未承認事項を残すpartialである。

重要な対応3点: 文案／省略のPM承認、検証基準／5領域の確定、本文の簡潔化。前二者はOQへ繰延べ、簡潔化はFinalize校正で行う。

| 観点 | 評価 | 重大度・所在・対応 |
| --- | --- | --- |
| Decision-ready | adequate | high／OQ-1・OQ-2: 未承認文案を確定要求として実装できない。PM承認前の実装禁止を維持する。 |
| Earned | strong | 読者・効果を仮説とし、名付きjourney・効果測定・期限を創作しない。 |
| Testable | adequate | medium／OQ-3・OQ-4: 個別の検査方法は明確だが提案段階。5領域名が確定するまで広い除外を適用しない。 |
| Honest scope | strong | 製品差分1行と工程文書作成を区別。RULE-1〜RULE-4と非目標で近接範囲の追加を防ぐ。 |
| Usable downstream | thin→adequate予定 | medium／全体: 初稿の公式word_metricsは総3592、前文25・目次251・前提132を除く本文3184。約3000語の目安に収めるため重複説明を校正で圧縮する。 |

## Done when

FR-1は既存READMEの説明改善という必要性へ直接つながり、一つの判定可能な結果を持つ。詳細journeyは一行の技術的変更に合わせ縮小し、架空の人物を作らない。非目標と境界が明確で、成功指標にはカウンター指標がある。文案・基準の承認は未取得であり、依頼者が全判断を済ませた状態とは扱わない。該当しない条件節は理由付きで除外し、必須セクションの空欄はない。

## 処置

high事項はOQ-1・OQ-2として保留、検証設定はOQ-3・OQ-4に保留。長さはreview-editorial.mdの校正で修正し、最終メトリクスを再計測する。
