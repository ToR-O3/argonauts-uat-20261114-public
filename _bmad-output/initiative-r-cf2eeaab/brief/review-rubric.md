# Rubric review

結論: 実装前の小規模メタデータ変更のBriefとして使用可能。確定値と旧指示の優先関係は明確で、製品受入を先取りしていない。

方式: 子起動ツールなしのため逐次セルフレビュー。本文、merged template、memlogを対象にrubric-planningを適用。stakesは内部の工程判断、altitudeは1項目変更のBrief。

## 優先して直す点

重要な修正指摘なし。追加要件を提案しない。

| Dimension | Rating | Severity | Location | Finding / fix |
|---|---|---|---|---|
| Decision-ready | strong | none | Executive summary / Decision record | 新設と厳密値、判断時刻、優先関係が明確。 |
| Earned | strong | none | Problem / What makes it different | 事業需要・差別化を創作せず、比較を当該変更に限定。 |
| Testable | strong | none | Success criteria | AC-1〜AC-3は厳密比較・差分確認・解析で確認可能。 |
| Honest scope | strong | none | Scope / Open questions | 製品変更しない本工程と後続実装を分離。依頼にない仮定なし。 |
| Usable downstream | adequate | none | 全文 | 必要な引用と工程境界があり、小規模変更の範囲内。 |

## Template done when

Executive summaryだけで対象、受益者である依頼者と実装・受入担当者、現在の追記条件の不一致を説明できる。各必須節は充足し、任意節の不採用理由をScopeに明記。未決事項なし。
