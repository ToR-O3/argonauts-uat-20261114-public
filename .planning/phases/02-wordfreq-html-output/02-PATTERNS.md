## Shared Patterns

### Acquisition and normalization stay outside formatters

**Sources:** tracked `wordfreq/sources.py:17–22`, `wordfreq/tokenizer.py:14–18`. **Apply to:** CLI/formatter wiring and boundary tests; neither source needs editing.
```python
    def read_text(self) -> str:
        try:
            with open(self._path, "r", encoding="utf-8") as source:
                return source.read()
        except (OSError, UnicodeDecodeError) as error:
            raise InputError(f"{self._path}: {error}") from error
```
```python
def iter_tokens(
    text: str, tokenizer: Callable[[str], list[str]] = default_tokenizer
) -> Iterator[str]:
    """Yield normalized tokens in their input order."""
    return (token.casefold() for token in tokenizer(text))
```
