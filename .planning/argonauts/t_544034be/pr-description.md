## 変わること

wordfreqで `--exclude FILE` を指定すると、ファイルに書いた単語を結果から外せます。大小の違いは既存と同じ扱いで、HTMLの総数は元の入力全体を保ちます。

UTF-8の1行1語を使い、前後空白を除いた空行・`#`開始行は無視します。除外ファイルが読めない場合や不正な行がある場合は、原因を知らせ、本文を読まずに終了します。除外後の絞込み・件数制限と、空の結果の表示を動作確認しました。READMEに実行例と空結果の説明があります。

**作成途中のため、まだマージしないでください。** 変更前との比較と独立した動作確認が残っています。
